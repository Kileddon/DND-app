# ADR-0001: SQLite current state plus append-only event log

- Status: accepted
- Date: 2026-09-02

## Context

Локальный host обязан подтверждать действия без облака, восстанавливаться после
перезапуска, дедуплицировать команды и сохранять аудит. Полный event sourcing увеличил бы
сложность первого среза и не требуется ТЗ.

## Decision

Использовать одну SQLite БД с нормализованными таблицами актуального состояния,
append-only `game_events` и `processed_commands`. Изменение состояния, событие и результат
идемпотентной команды записываются одной транзакцией. SQLAlchemy records не являются
доменными сущностями; Alembic управляет схемой.

## Consequences

- Чтение и восстановление после перезапуска не требуют replay всей истории.
- Журнал остаётся пригодным для аудита, отчётов и будущей sync queue.
- Компенсирующие события и облачная очередь ещё должны быть реализованы отдельными
  срезами.
- Схему события потребуется мигрировать версионированно; поэтому каждое событие уже
  содержит `schema_version`.
